## 🏖️ About The Project

**Adithya Beach Villa** is a real-world hospitality website developed to create a modern digital presence for a villa rental property.

The website provides visitors with an easy way to:

- Discover the villa
- Explore the property
- View amenities
- Browse property photographs
- Understand the stay experience
- Find the location
- Contact the property
- Make booking enquiries

The project focuses on combining **modern frontend engineering, responsive design and hospitality-focused UI/UX** into a polished customer experience.

The visual direction was created around the atmosphere of a premium villa and hospitality experience.

### 01 / PROPERTY-FIRST VISUALS

Large property imagery remains the primary focus of the experience.

### 02 / CLEAN VISUAL HIERARCHY

Content is organized clearly so visitors can quickly understand the property.

### 03 / MODERN TYPOGRAPHY

The property remains the primary focus while the interface supports the guest journey.

# 🚀 Getting Started

## 1. Clone the repository

**git clone https://github.com/pratyushcse/Adithya_Beach_Villa.git**

## 2. Enter the project

**cd Adithya_Beach_Villa**

## 3. Install dependencies

**npm install**

## 4. Start development server

**npm run dev**

The development server will start locally.

---

# 📦 Production Build

Create an optimized production build:

**npm run build**

Vite generates the production files inside the **dist** folder.

Preview the production build locally:

**npm run preview**

---

# 🚀 Deployment

The project is deployed using **Vite, gh-pages and GitHub Pages**.

Deploy the latest production version using:

**npm run deploy**
